# Kaskelkinder Website

A website for **Kaskelkinder**, a parent-run childcare initiative (_Kinderladen_) in Berlin. Built as a freelance project to give the initiative a modern, welcoming online presence.

## Tech Stack

- **React** + **TypeScript** (Vite)
- **MUI (Material UI)** – custom theme with responsive typography and component overrides
- **Framer Motion** – animated mobile navigation
- **Sanity CMS** – content management for the team

## Features

- Fully responsive layout with mobile-first navigation
- Animated burger menu with sequenced open/close transitions (Framer Motion)
- Custom MUI theme with HSL color palette, responsive typography scale, and breakpoint-aware page padding
- Team page with dynamic color-coded portrait cards
- Photo gallery
- Multiple content pages: Concept, Facilities, Initiative, Team, Jobs, Support, Contact
